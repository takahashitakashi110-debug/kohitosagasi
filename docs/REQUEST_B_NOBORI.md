# 依頼書 B: ノボリユラシの決定的瞬間を「旗を抱きしめる」絵にする v1.0

対象: Codex CLI（実装担当）
前提: `AGENTS.md` と `docs/WORKFLOW.md`（v0.2 以降）の手順に従うこと。
この依頼は**新しい Issue・新しいブランチ・新しい PR** で進める（WORKFLOW.md §4）。

---

## 0. 目的

ノボリユラシの決定的瞬間は、ゲーム中に「**旗を抱きしめている**」と表示される（`src/data/text.ts` の `actions.noboriyurashi`）。
ところが今の絵（`src/render/kohitoArt.ts` の `drawNoboriyurashi`）は、通常時より少し大きく揺れるだけで、

- 表示の文と絵が合っていない
- 通常時と見分けにくい（依頼 A のレビューで「任意」として残した指摘）

この依頼で、決定的瞬間の絵を「**のぼり旗の布を胴に巻き付けて抱きしめている**」形にし、通常時と形で見分けられるようにする。

## 1. 変更してよいファイル

- `src/render/kohitoArt.ts`（`drawNoboriyurashi` のみ）
- `src/render/palette.ts`（色の**追加**のみ。既存の値は変えない）
- `tests/art.test.ts`（§4 のテストを追記。既存のテストは弱めない）
- `docs/HANDOVER.md`（対応済みの記録）

**変えてはいけないもの**: 他のこひとの絵、通常時（`special=false`）のノボリユラシの見た目、ゲームのルール、採点、テキスト、`camera.ts` / `field.ts`。

## 2. 描画範囲（変更なし・厳守）

依頼書 A（`docs/REQUEST_A_ART.md`）§2 と同じ。ノボリユラシは x: **-20〜24**, y: **-30〜16**。
どの時刻（`elapsed` 0〜6 秒）でも収めること。既存の範囲テストがそのまま守る。

## 3. 決定的瞬間のデザイン

- **布（色あせた赤、`P.red`）が胴に巻き付く**。右へたなびいていた布が、胴を包むように**胴の幅の近くまで寄る**。
  - 布の右端は、胴の右端（x = -5 付近）から **最大でも x = 4 まで**。
  - 布の上下の範囲は、通常時とおおむね同じでよい（胴の上半分〜下半分を包む）。
- **腕が布の上から胴を抱える**: 胴の左右から短い腕（`P.skin` の線か楕円）が出て、布を押さえている。
- **目**: 3つの目を、うっとりした**閉じ目**（短い横線か下向きの弧）にする。
- **濡れ**: 布の下端から、しずくが**2つ**落ちる（通常時は1つ）。範囲内で消すこと。
- 揺れ（`lean` / `wave`）は小さくしてよい（抱きしめて止まっている様子）。
- 描画命令は30個以内（既存テストが守る）。

通常時（`special=false`）の絵は**1ピクセルも変えない**こと。

## 4. テスト（`tests/art.test.ts` に追記）

既存の `RecordingContext` に、**塗った色ごとの範囲**を記録する仕組みを足してよい（既存の判定は変えない）。

1. **布が寄っている**: ノボリユラシの `special=true` で、`elapsed` 0〜6 秒（0.1 秒刻み）のすべてで、
   `P.red` で塗った範囲の右端が **4 以下**。
2. **通常時は今までどおり**: `special=false` で、`P.red` の範囲の右端が **15 以上**（どの時刻でも）。
   これは通常時の絵を変えていないことの確認を兼ねる。
3. **通常時の絵が変わっていない**: `special=false`, `elapsed=0` の描画命令の列（メソッド名と引数）が、
   変更前と完全に一致する（変更前の記録をテスト内に固定値として置いてよい）。

既存の 134 件は1件も壊さないこと。重要なテスト（`tests/art.test.ts`）への**追記**は、この依頼書で了承済み（WORKFLOW.md §5）。既存の期待値の変更・削除は不可。

## 5. 受け入れ条件

1. `npm run typecheck` / `npm test` / `npm run build` が通る（134件＋§4 の追加分）。
2. PR の CI が ✅。
3. `tools/art-preview.html` の2段目（決定的瞬間・4倍）で、ノボリユラシが「旗を抱きしめている」と読める。
   4段目（影絵・実寸）の通常時は変わっていない。
4. §1 のファイル以外を変更していない。
