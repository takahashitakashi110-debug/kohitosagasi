# H: 夏休みの町とこひとの見た目の刷新

## 目的
ユーザーの依頼: Runwayを使い、6体のこひとを名前にふさわしい姿へ描き直し、散策する町全体を夏休みにふさわしい舞台にする。季節はユーザーが夏休みを選択。

## 対象
- キャラクター: ウラスミ=低く横長の隅の住人、ハリツキ=薄い貼り付き体、ドブノゾキ=3つ目で排水路を覗く、ノボリユラシ=旗と棒の体、カゲボウシ=折りたたむ影、たれじり=単一の半透明の垂れる餅状の尻。
- 各通常姿・決定的瞬間と、たれじりの隠れ姿をローカル画像として組み込む。読み込み中や失敗時も既存ベクターで遊べる。
- 全4スポットの建物・舗装・植栽・小物を夏の町に統一。商店街=日よけと朝顔、川沿い=乾いた水路と夏草、団地=木陰と花壇、駅前=夏の日差しと街路樹。
- タイトルと地図も夏の町に合わせる。Runway画像はゲームに同梱し、実行時の外部通信はしない。

## 変えてはいけないもの
出現条件・移動・撮影採点・推理・セーブ・タイル通行判定・既存の日本語名。ゲーム内文字はtext.tsに集約。重要テストと既存パレットの色値は変更しない（元のベクターの後方互換性も維持）。たれじりは桃型にせず、隠れているときは尻のみ。

## テスト条件・受け入れ条件
- npm run typecheck / npm test / npm run build / 実ブラウザe2eが成功。
- 画像読み込み済み経路で14種のフレーム切り替えと全画像の採点矩形内描画、隠れ尻の範囲を新規テストで検証。読み込み失敗時のフォールバックも検証。
- 390×844 / 360×640でUIが重ならず、散策・カメラ・アルバム・エンディングに新しいキャラクターが反映される。画像の404とJavaScriptエラーなし。
- 既存テストは変更・削除・skipしない。
- 本流へ直接pushせず、PRで提出。mergeと公開URLへの反映は持ち主が行う。
