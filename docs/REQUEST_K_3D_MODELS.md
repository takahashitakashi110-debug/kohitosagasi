# K: 10キャラの3Dモデル（試作完成後）

持ち主が2026-11-23の本チャットでRunwayによる各キャラの3Dモデル作成を依頼。
対象はこひと6体＋町の大人4人。2D試作を完成した後に進める。

## 用意するもの

- 既存の原画から各キャラ1枚ずつを切り出した参照画像。
- Runwayで参照画像からテクスチャ付きのGLBを各1個生成する。
- 原画のシルエット、小道具、色、こひと6体の形を維持する。
- たれじりの尻は単一で、桃型や二つの丸い形にしない。
- 旗の棒と布、住人の帽子・傘・巻き尺・じょうご・竹ざおを確認する。
- standard geometry / standard textures / PBR、最大50,000 facesを初期設定とする。
- リグ、歩行アニメーション、一人称描画への接続は別途の工程。生成GLBだけで動くゲームに組み込まれたとは扱わない。

## 現状と費用

接続済みRunwayには3D生成権限がある。画像参照＋標準テクスチャは1体30クレジット、
10体で計300。効果音までの生成後、残高は0。現時点で3D生成は未実行。
追加購入や課金操作は行わない。クレジットが用意できたら実残高と各生成の見積りを
確認してから進める。品質向上設定や再生成の費用は含まない。

## 再開

`scripts/prepare-model-references.py` で10枚の単体参照と `requests.json` を作れる。
今回の成果物には `3d-inputs/` として準備する。原画のRunwayタスクIDは
`src/assets/summer/README.md` と `src/assets/townspeople/README.md` を参照。
生成後はダウンロード、実ファイルの検証、10体の目視確認、GLBへのリンクを返す。
