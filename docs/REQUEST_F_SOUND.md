## 0. 目的

今のゲームは完全に無音。「忍び足で近づく」「息をひそめてピントを合わせる」「シャッターを切る」という遊びの手ざわりを、音で強める。

- **音声ファイルは使わない**（外部アセット 0 の制約を守る）。ブラウザの **Web Audio API で音をその場で合成**する。
- 音は**雰囲気づけ**で、ゲームのルール・採点・進行・警戒度には一切影響させない。

## 1. 変更してよいファイル

- `src/audio/`（新規フォルダ）… 音の設計と再生

- `src/scenes/title.ts`、`src/scenes/field.ts` … ミュート切り替えボタンの**描画の追加**のみ
- `src/data/text.ts` … ミュート関係の文言の追加
- テストファイルの追加
- `docs/HANDOVER.md` … 対応済みの記録

**変えてはいけないもの**: `src/game/` のすべて（ルール・採点・警戒度・セーブ）、`SaveData` の形、絵、マップ、既存のテストファイル。

## 2. 鳴らす音（きっかけはすべて `main.ts` で検出する）

| 音 | きっかけ | 音の方向性 |
|---|---|---|
| 足音（通常） | 散策中に `game.moving` が真で、前回の足音から **22px 以上**動いたとき | 短い（0.08 秒以下）乾いた「こつ」 |
| 足音（忍び足） | 同上で `game.sneaking` が真のとき。間隔は **34px 以上** | 通常より**小さく**、柔らかい |
| ピント | カメラ画面で長押し中、ピント（`heldMs / 1200`）が 0.6 と 1.0 を**超えた瞬間**に1回ずつ | 小さな「ぴっ」 |
| シャッター | 撮影の結果（`game.feedback`）が出た瞬間 | 「かしゃ」（ノイズの短い2連） |
| ヒント入手 | `game.feedback.hintGained` が真の結果が出た瞬間（シャッターの後に） | 明るい3音の上がる旋律 |
| 鳴き声 | 散策中、プレイヤーから **160px 以内**のこひとの `specialRemaining` が 0 から正に変わった瞬間 | こひとごとに違う短い音型（下表） |

## 3. 設計（テストできる形にする）

1. **音の設計図は純粋な関数にする**: 例 `planSound(event): Note[]`。`Note` は波形・周波数（開始と終了）・長さ・音量・開始の遅れなど。
   Web Audio を使わずに中身を検査できるようにする。
2. **きっかけの検出も純粋な関数にする**: 例 `detectSoundEvents(prev, next, state): SoundEvent[]`。
   前フレームと今フレームの状態（必要な値だけを写したもの）から、鳴らす音の一覧を返す。足音の距離の累積などの状態もここで扱う。
3. **再生だけが Web Audio に触る**: `AudioContext` は**最初のユーザー操作（キー入力・タップ）のときに作る／`resume()` する**
   （ブラウザの自動再生の制限のため）。`AudioContext` が無い環境・作れない環境でも例外を出さず、無音で動き続けること。
4. **ミュート**: タイトル画面と散策画面の右上付近に小さな切り替えボタン（キーボードは `M`）。
   設定は `localStorage` の**別のキー** `kohitosagasi.settings.v1` に保存する（`SaveData` は変えない。読み書きは try/catch で包む）。初期値は音あり。
5. **音量の上限**: 全体の音量（マスター）は **0.3 以下**。1つの音の長さは **1 秒以下**（エンディングのみ合計 4 秒以下）。

## 4. テスト（新規ファイル）

1. `planSound`: すべての種類の音について、長さ・音量の上限（§3-5）を守る。6体の鳴き声がすべて互いに違う。
   **忍び足の足音は、通常の足音より音量が小さい**。
2. `detectSoundEvents`:
   - 通常歩行で 220px 動くと足音がおよそ 10 回（22px ごと）、忍び足で 340px 動くとおよそ 10 回（34px ごと）。止まっていると鳴らない。
   - ピントの音は 0.6 と 1.0 を超えた瞬間に1回ずつで、押し続けても繰り返さない。
   - 結果が出た瞬間にシャッターが1回。ヒントありのときだけヒントの音が続く。
   - 160px より遠いこひとの決定的瞬間では鳴き声を出さない。
   - 逃げた数が増えたときだけ逃げた音、エンディングに入った瞬間だけエンディングの音。
3. ミュート中は、再生の層に音を渡さない（偽の再生先で確かめる）。設定の保存は `localStorage` が例外を出しても落ちない。
4. 既存の 358 件は1件も変えずに通ること。
