## 0. 目的

4つのスポット（商店街・川沿い・団地・駅前）は、目印（`src/render/tiles.ts` の `drawObjects`）が画面中央付近に1か所あるだけで、
576×768 のマップの大半は素のタイルになっている。歩き回っても景色が変わらず、「まちを散策している」感じが薄い。

この依頼で、**スポットごとの「らしさ」が出る装飾（小物）を、マップ全体に配置して描く**。
装飾は**見た目だけ**で、当たり判定・こひと・採点・進行には一切影響させない。

## 2. 配置データ（`src/data/props.ts`）

```ts
export type PropKind = /* §3 の種類 */;
export interface Prop { kind: PropKind; x: number; y: number; w: number; h: number; solid: boolean }
export const PROPS: Record<SpotId, Prop[]>;
```

- `x, y, w, h` はマップ上の論理px（左上原点、マップは 576×768）。装飾はこの矩形の中だけに描く。
- `solid` は「**障害物に見える**もの」（ベンチ、ゴミ箱、自転車、看板の柱など）なら `true`、
  地面の模様・ひび・線・しみ・落ち葉など**踏めるように見える**ものなら `false`。

### 配置のルール（すべてテストで守る。§4）

1. 各スポットに **8〜14 個**、そのうち種類は **4 種類以上**。
2. 矩形はマップの内側に収まる（0 ≤ x、x+w ≤ 576、0 ≤ y、y+h ≤ 768）。
3. **`solid: true` の装飾は、通れないタイル（`1` か `3`）の上だけに置く**（矩形が重なるタイルがすべて `1` か `3`）。
   通れる場所に障害物が見えると、プレイヤーが「通れない」と誤解するため。
4. そのスポットに出るこひと（`src/data/kohito.ts` の `KOHITO`）の立ち位置から、矩形の最も近い点まで **48px 以上**離す。
   たれじりは川沿いに出るので、川沿いでは `dobunozoki` と `tarejiri` の両方から離す。
5. `SPAWN`（288, 420）から 48px 以上離す。
6. 既存の目印の範囲（各スポットで x 240〜390, y 180〜350）と**重ならない**。
7. 装飾どうしは重ならない。

## 3. スポットごとの装飾（種類の例。名前と描き方は判断してよい）

「日照りの夏の、地方の古いまち」の空気を出す。くすんだ色（既存パレット中心）で、**こひとより目立たないこと**。

| スポット | 例 |
|---|---|
| 商店街 `shoutengai` | 閉店した店のシャッター（建物タイルの上）、色あせた看板、ベンチ、ゴミ箱、地面の白線、落ちたチラシ |
| 川沿い `kawazoi` | 干上がった水路の筋とひび、手すりの柵、枯れ草の束、乾いた水たまりの跡、石 |
| 団地 `danchi` | 棟の窓の列（建物タイルの上）、自転車、掲示板、植え込み、地面のタイル模様 |
| 駅前 `ekimae` | 横断歩道や縁石の線、バス停の標識、時計の柱、タクシー乗り場の線、ガムの跡 |

- 時間帯の色かぶせ（`drawWorld` の最後の `P.time`）は既存のまま全体にかかるので、装飾側で時間帯の処理はしなくてよい。
- **乱数を使わない**（`Math.random` 禁止）。毎フレーム同じ見た目になること。揺れなどのアニメーションを入れる場合は `elapsed` だけを使う。

## 4. テスト（新規ファイル。名前は任意）

1. §2 の配置ルール 1〜7 を、4スポットすべてで検査する。
2. **決まった見た目**: 同じ引数で装飾を2回描くと、描画命令の列が完全に一致する（`Math.random` を使っていない確認を兼ねる）。
3. **描画の重さ**: 1スポットの装飾すべてを描くときの `fill` / `stroke` / `fillRect` / `strokeRect` の合計が **160 回以下**
   （散策画面は毎フレーム全体を描くため）。
4. **はみ出さない**: 各装飾の描画が、自分の矩形（`x, y, w, h`）から外にはみ出さない（線の太さの半分まで許容）。
   依頼 A の `tests/art.test.ts` の記録用コンテキストと同じ考え方でよい（必要なら同じ仕組みを新しいテストファイルに作る。`art.test.ts` は変えない）。

既存の 191 件は1件も変えずに通ること（`tests/playthrough.test.ts` の3日間クリアを含む）。

## 5. プレビュー（`tools/map-preview.html`）

`npm run dev` 中に `/tools/map-preview.html` で開ける静止ページ。4スポットそれぞれの**マップ全体**（576×768 を 0.5 倍）を、
タイル → 装飾 → 既存の目印 → こひと（その場所に出る全員）の順で描いて並べる。装飾の矩形を枠線で重ねる表示の切り替えがあるとよい。
ビルド成果物には入れない。
