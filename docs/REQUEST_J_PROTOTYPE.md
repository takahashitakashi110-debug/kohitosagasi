# J: 動くこひとと町の大人を撮影できる試作

## 目的と持ち主の指示
2026-11-23の本チャットで「こひとが少し動き、撮影が難しくなると楽しい」、Runwayで「こひと6体＋町の大人4人」の「ゲーム用の連続コマ画像」を作成し、「一旦完成品まで貫通、今回を試作とする」と明示指示。
現在の2D版で素材作成から実装・試験・遊べるビルドまで完了する。既存PR #22 / codex/summer-artを継続して対象を拡張し、Issue #23の住人配置も同じ試作へ統合する。新しいPRは作らない。

## 対象と実装契約
- Runway由来のこひと6体（隠れ尻を含む）・住人4人の各4コマをローカル同梱。未読込・失敗時も従来絵で遊べる。
- こひとは出現地点付近を少し移動し、定期的に止まる。障害物を抜けず遠ざかり続けない。たれじりの隠れ姿は遮蔽位置を維持する。
- カメラを構えた時点の狙いを保持し、移動中の被写体を自動追従し続けない。描画と採点は同じ現位置・カメラ中心を使う。止まったタイミングで従来どおり全身撮影ができる。
- 4スポットに風変わりな日課を持つ大人を1人ずつ配置し、撮影すると外れ結果を表示して散策へ戻る。ヒント・6体のアルバム・クリア条件は変化させない。
- 近くの対象を選べる形にし、住人がこひとの撮影を妨げない。住人写真は既存のこひとセーブに混入させない。
- 主人公設定は夏休みの1週間だけ祖母の町へ来た子ども。現行2Dで試作を完成し、一人称化はこの試作には含めない。

## 受入条件
- 10キャラの連続コマを実ブラウザで確認し、こひとは小さく移動・停止する。
- 描画と撮影矩形が一致し、動く6体を全身撮影でき、隠れ→全身→エンディングまで遊べる。
- 住人4人を撮影でき、外れ結果の表示・復帰と既存記録の不変を確認する。
- 390×844 / 360×640で操作・ボタン配置・読込失敗時の継続を確認。外部画像通信・404・JavaScriptエラーなし。
- 型チェック・既存を含む単体・ビルド・e2e成功。別AIレビュー、CI確認、完成した試作の成果物と遊び方を提示。mergeはしない。
