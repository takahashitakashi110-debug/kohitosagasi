# 依頼書 E: スポットの描き分けの強化（タイル配置と装飾の見えやすさ） v1.0

対象: Codex CLI（実装担当）
作業場所: この依頼書が入っているブランチ `codex/spot-layout` と、そのドラフト PR（Issue に番号を記載）
前提: `AGENTS.md` と `docs/WORKFLOW.md`（v0.4 以降）に従うこと。**新しいブランチや PR は作らない**。

## 0. 目的

依頼 D でスポットに装飾を置いたが、まだ4スポットの見分けがつきにくい。原因は2つある（検算済み）。

1. **商店街・団地・駅前のタイル配置が完全に同じ**。通れる／通れないの配置が 768 マス中 0 マスしか違わない（川沿いだけがほかと 80 マス違う）。
2. **装飾が薄い**。`src/render/props.ts` の透明度が 0.22〜0.55 で、ゲーム画面ではほとんど見えない。

この依頼で、**商店街・団地・駅前のタイル配置をそれぞれの「らしさ」が出る形に作り直し**、**装飾を見えやすくする**。

## 1. 変更してよいファイル

- `src/data/spots.ts` … `shoutengai` / `danchi` / `ekimae` のタイル配列のみ。**`kawazoi` と `SPAWN`、マップの大きさ（24×32）は変えない**
- `src/data/props.ts` … 新しいタイル配置に合わせた装飾の位置・大きさ・種類の調整
- `src/render/props.ts` … 透明度・色・線の太さの調整（形の大きな変更は不要）
- `src/render/palette.ts` … 色の**追加**のみ
- `tools/map-preview.html` … 必要なら調整
- テストファイルの追加
- `docs/HANDOVER.md` … 対応済みの記録（§7）

**変えてはいけないもの**: こひとの位置・絵・採点、既存の目印（`drawObjects` の本体）、当たり判定の処理（`src/game/world.ts`）、
タイルの種類（0〜4）の意味、**既存のテストファイル**（`tests/props.test.ts` を含め、すべて変更せずに通すこと）。

## 2. タイル配置のルール（すべてテストで守る。§4）

対象は作り直す3スポット（`shoutengai` / `danchi` / `ekimae`）。「通れない」はタイル `1` と `3`、「通れる」は `0` `2` `4`。

1. **外周はすべて `1`**（1行目・32行目・1列目・24列目）。
2. **守る範囲は変えない**: 列 9〜16・行 7〜14（ピクセルで x 216〜407, y 168〜359）のタイルは、今の値のまま。
   既存の目印・こひと・たれじりの遮蔽がこの範囲にあるため。
3. `SPAWN`（288, 420）のタイルは通れる。
4. **たどり着ける**: `SPAWN` のタイルから上下左右に通れるタイルをたどって（幅優先探索でよい）、
   - そのスポットに出るすべてのこひとについて、**こひとの立ち位置から中心までの距離が 60〜100px のタイル**に1つ以上たどり着ける。
   - 通れるタイル全体の **90% 以上**にたどり着ける（行けない小部屋を作らない）。
5. 通れるタイルの割合は **45%〜75%**（迷路やがらんどうにしない）。
6. **描き分け**: 4スポット（川沿いを含む）のどの2つを比べても、通れる／通れないが違うタイルが **120 マス以上**ある。

### 作り直しの方向（例。具体的な形は判断してよい）

| スポット | らしさ |
|---|---|
| 商店街 `shoutengai` | 南北に長いアーケード通り。中央に幅3〜4マスの通り、その両側に店の建物が細かく連なる。横道が2〜3本 |
| 団地 `danchi` | 横長の棟（建物）が3〜4列、平行に並ぶ。棟と棟の間に広場や植え込み（`2`）がある |
| 駅前 `ekimae` | 北側に横長の大きな駅舎。中央付近に通れない植え込みの島（ロータリー）があり、その周りを歩ける。南側は広い歩道 |

## 3. 装飾の見えやすさ

- 装飾の塗り・線の透明度（`globalAlpha`）は **0.5〜0.8** にする（今は 0.22〜0.55）。0.8 を超えない＝こひとより目立たせない。
- 特に川沿いの「干上がった水路」（ひび・泥の跡）が、ゲーム画面で一目でわかる濃さにする。
- 依頼 D の配置ルール（`tests/props.test.ts` が守る7項目、描画命令 160 回以下など）は**そのまま満たす**こと。
  タイル配置が変わって障害物風の装飾が通れるタイルに乗る場合は、`props.ts` の位置を動かして合わせる。

## 4. テスト（新規ファイル。名前は任意）
