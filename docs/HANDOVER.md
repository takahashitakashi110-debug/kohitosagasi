## 4. 決まっていること（と、その理由）

設計 v0.3 の未決事項6件は全部決定済みです。**理由も含めて覆さないでください。**

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 時間進行 | スポット移動で1区分進む | 待ち時間ゼロ。狙った時間帯へ行けるので「ヒントを元に計画する」遊びになる |
| 出現条件 | ヒント5つの消去法で「川沿い×夕」に確定 | アルバムのメモがそのまま推理表になる |
| エンディング | 雨は降らせない。水たまりだけ | 救済をこひとに背負わせない。観察ゲームらしい幕切れ |
| 撮影操作 | 長押しでピント → 離してシャッター | 片手で遊べて、評価軸4つが自然に全部乗る |
| 主人公 | 夏休みにあつぎへ来た子ども | よそ者だから「まちの違和感」に気づける＝こひとが見える理由 |
| ライブラリ | 使わない（素の TS + Canvas 2D） | MVP の規模に対して過剰。仮絵と相性がよい |
| タイトル | こひとさがし | 「さがす（捕まえない）」が差別化方針そのもの |

**差別化方針**（既存作品と被らせないための約束）も維持してください。

- こひとは**捕まえない**。罠もない。観察手段は写真だけ
- 「図鑑」ではなく「あつぎこひと観察アルバム」
- たれじりの尻は桃型にしない。餅／水まんじゅうのように垂れて伸びる半透明
- 名前はカタカナ複合語ばかりにしない（ひらがなを混ぜる）
- 実在の地名・店名・施設名を使わない

## 6. 触るときの地雷（重要）

### 地雷1: 採点式の重みは合計 0.9

`src/game/photo.ts` の重みは 範囲 0.40 / ピント 0.30 / 距離 0.20 で、
**決定的瞬間なしの満点は 90 点**です。S は 85 点以上なので、
決定的瞬間を引かなくても S は取れます（運に依存させないための意図）。
重みを足し引きするとランクの分布が変わるので、`tests/photo.test.ts` も一緒に直してください。

### 地雷2: こひとを足す／配置を変えると、推理が壊れる

5つのヒントは「どの4つを選んでも絞りきれない」ように組んであります。
こひとを増やす・ヒントを変える・正解マスを動かすと、この性質が簡単に崩れます。
`tests/deduction.test.ts` が総当たりで守っているので、**先にテストを直してから実装**してください。

### 地雷3: たれじりの絵を変えると、3か所が連動する

これが一番踏みやすいです。たれじりの見た目・判定・遮蔽が**別々の場所に数値で散っています**。

| 場所 | 内容 |
| --- | --- |
| `src/render/kohitoArt.ts` の `drawTarejiri` | たれじり本体の絵（隠れ時は胴を描かない） |
| `src/scenes/field.ts` の `drawWorld` 内の `fillRect(k.x - 18, k.y - 39, 28, 33)` | 隠れ時に胴を隠す遮蔽の矩形 |
| `src/data/kohito.ts` の `SUBJECT_BOUNDS.tarejiri`（`subjectRect` が参照） | 採点に使う被写体の矩形 `{left:-15, top:-37, w:35, h:62}` |
| `src/scenes/camera.ts` の `evaluateCamera` 内の `visibleFinder` | 隠れ時に「見えている尻の範囲」へ狭める矩形 |

**絵だけ直して採点側を放置すると、隠れているのに全身写真が撮れてしまい、
いきなりクリアできてしまいます。** 必ず4か所セットで直し、
`playthrough.test.ts` の「隠れた尻だけでは全身にならない」が通ることを確認してください。

### 地雷4: 表示文字列は `src/data/text.ts` にだけ置く

他のファイルに日本語をハードコードしないでください（コメントは日本語で可）。

### B. 遊びの既知の不具合2件 → **対応済み**

> 対応内容: カメラ画面の中心を `cameraCenter()`（`src/game/world.ts`）で
> プレイヤー→対象へ 0.6 だけ寄せ、描画（`field.ts` の `drawWorld`）と採点（`camera.ts` の `subjectRect`）が
> 同じ式を使うようにした。逃走記録は `SaveData.escaped` に保存し、時間が進むと空にする
> （古いセーブに無い場合は空配列で補う）。テストは `tests/camera.test.ts`（8方向から全身が撮れる）と
> `tests/playthrough.test.ts`（逃走→リロード→出ない）、`tests/save.test.ts` に追加。
> ブラウザで「真下 120px から構えて全身・評価A」を確認済み。
>
> 以下は対応前の記録。

1. **カメラが縦に振れず、上下からだと撮れない**（`src/scenes/camera.ts:17-21`、`src/main.ts` の camera 分岐）
   - カメラ画面は**プレイヤー中心**に 1.6 倍拡大し、パンは横 ±48（画面px）のみ。
   - 計算上、通常のこひと（44×46）を `full` で枠に収められるのは
     **縦のずれ約 67 px 以内・横のずれ約 75 px 以内**。
     一方カメラアイコンは距離 **120 px 以内**で出るので、
     真上／真下 70〜120 px から構えると「撮れるはずなのに全身が入らない」。
   - 直し方の案: カメラ画面の中心を「プレイヤー→対象こひと」の方向へ寄せる
     （例: 中心 = プレイヤー + (対象 − プレイヤー) × 0.6）か、縦パンも許す。
     どちらでも `subjectRect` と描画（`drawWorld` のカメラ表示）を**同じ式**で動かすこと。
   - 追加テスト: 真上 100 px のこひとに対し、パンを適切にすれば `framing === "full"` になる。

2. **リロードすると逃げたこひとがすぐ戻る**（`src/game/state.ts` の `SaveData`、`src/main.ts` の continue 処理）
   - `game.escaped` はメモリ上だけで、`SaveData` に入っていない。
     タイトルの「つづける」で `escaped.clear()` されるため、
     逃げられた直後にリロードすれば同じ時間区分で再挑戦できてしまう。
     たれじりの「逃げたらその日の夕にはもう出ない」も同じ抜け道で無効になる。
   - 直し方の案: `SaveData` に `escaped: KohitoId[]` を足し（時間が進んだら空にする）、
     `save.ts` の検証にも追加する。`version` を上げるか、欠けていたら空配列で補う。
   - 追加テスト: 逃走 → 保存 → 読み込み → 同じ時間区分の `enterField` で出現しない。
