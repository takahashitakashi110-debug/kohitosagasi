# こひとさがし ゲームデザイン v0.4

> ステータス: v0.3 の未決事項6件を決定した版。MVP の実装指示書は [docs/MVP_SPEC.md](./MVP_SPEC.md)。

## 1. コンセプト

架空のまち「あつぎ」は、雨がほとんど降らない夏を迎えている。
そこに、こひと「かくれたれじり（隠れ垂れ尻）」が現れたという噂が広まり、
きもかわいいこひとたちが、まちのあちこちに集まってきた。

プレイヤーは見下ろし視点でまちを歩き、こひとに気づかれないように近づいて**スマホで写真を撮る**。
撮った写真から生態のヒントを集め、最後に、かくれたれじりの全身を撮影することを目指す。

- 正式タイトル: **こひとさがし**
- ジャンル: 散策＋観察（見下ろし視点で歩く）
- 遊べる環境: ブラウザ（スマホ優先、PC対応）
- 雰囲気: ゆるキモ（子どもも遊べる程度の気持ち悪さ）
- 絵: 最初は仮絵（図形やSVG）。遊びが固まってから本番の絵に差し替える

### 既存作品との差別化方針

- こひとは**捕まえない**。罠もない。観察手段は写真だけ。
- 記録媒体は「図鑑」ではなく、**あつぎこひと観察アルバム**（写真＋メモ）と呼ぶ。
- かくれたれじりのお尻は桃型にしない。餅や水まんじゅうのように**垂れて伸びる半透明の尻**にする。
- 名前は「場所＋行動」のカタカナ複合語ばかりにしない。ひらがなを混ぜたり、語感を崩したりする。

## 2. 世界観

### 舞台: あつぎ（架空）

- ひらがな表記にして、実在の厚木市とは別のまちとして扱う。実在する店名や施設名は使わない。
- 雨が降らず、川の水位が下がり、側溝も干上がっている。
- MVP のスポット: **商店街／川沿い／団地／駅前**（＋拠点としての「いえ」）

### 主人公

- **夏休みの1週間だけ、おばあちゃんの住む町「あつぎ」へ遊びに来た子ども**。
- こひとが見える理由: よそ者だから「まちの違和感」に気づける。
  住んでいる人には見慣れた景色が、主人公にはいちいち引っかかる。
- 1日の終わりにおばあちゃんの家（いえ）へ帰り、その日の写真をアルバムに整理する。

### 物語の芯: なぜ、こひとが集まるのか

- かくれたれじりの垂れた尻からは、少しずつ**しずく**がしみ出している。
- 日照りで水場を失ったこひとたちは、そのしずくを飲みに集まってくる。
- かくれたれじりは恥ずかしがりで、隠れ方が下手（いつも尻だけがはみ出している）。
- **エンディング（確定）**: 全身を撮ると、たれじりがまちの干上がった水路に座り込み、
  しずくで小さな水たまりを作る様子が見られる。そこへこひとたちが集まってくる。
  **雨は降らせない。** 救済をこひとに背負わせず、「この生き物がここにいた」という
  観察ゲームらしい幕切れにする。

### かくれたれじりの出現条件（確定）

4スポット × 4時間区分 = **16マス**の中から、5体のこひとのヒントで
**1マスだけに絞り込める**ように組む。ヒントは1つずつ候補を消していく消去法で、
5つ全部そろって初めて確定する（正解は **川沿い × 夕**）。

| # | ヒント元 | ヒントの文面 | 消える候補 |
|---|---|---|---|
| 1 | じはんきウラスミ | 「たれじりは、人の行き来がある時間には出てこない」 | 朝・昼（残8） |
| 2 | シャッターハリツキ | 「商店街のシャッターが湿るのは、通りすぎた時だけ。居つく場所じゃない」 | 商店街（残6） |
| 3 | ノボリユラシ | 「たれじりは団地の北側の影を"通る"。立ち止まりはしない」 | 団地（残4） |
| 4 | ダンチカゲボウシ | 「しずくの匂いは、人の多いところでは消えてしまう」 | 駅前（残2） |
| 5 | ドブノゾキ | 「日が落ちきると、たれじりは水路から出ていく」 | 夜（残1 → 川沿い×夕） |

- ヒントは、そのこひとを**「生態メモ」段階まで撮れた**ときに手に入る（雑な写真ではもらえない）。
- 全ヒントがそろうまで、たれじり本体は出現しない。代わりに各スポットへ
  「通った跡」（湿ったシャッター、しずくの跡）がランダムに現れ、雰囲気だけを出す。
- MVP では正解を固定する。日替わりランダム化は後の検討事項。

## 4. ゲームの流れ

### 時間（確定: スポット移動で進む）

- 1日は **朝・昼・夕・夜** の4区分。
- 1日の始まりは「いえ」で朝。まちの地図からスポットを選んで出かける。
- **スポットを出て次のスポットへ移動すると、時間が1区分進む。**
  同じスポットに留まっている間は時間が進まない（粘っても損をしない）。
- 夜の散策を終えると家に帰り、その日のまとめ画面でアルバムを整理する → 翌日の朝へ。
- つまり1日に行けるのは最大4回。
  同じ時間区分にこひとが重なっている（商店街・夕 と 川沿い・夕、駅前・夜 と 団地・夜）ため、
  ヒント5つをそろえるのに最短2日、クリアまで最短3日かかる。
- 日数の上限はない（失敗して終わることはない）。かかった日数は記録として残す。

### 散策（見下ろし視点）

- スマホは画面左下の仮想スティック、PC はキーボード（WASD / 矢印）で操作する。
- 普通に歩くと足音が立つ。**忍び足**（ゆっくり移動）にすると、こひとに気づかれにくくなる。
- 「違和感」に近づくと、カメラのアイコンが出る。

### 撮影（確定: 長押しでピント → 離してシャッター）

- カメラを構えると、画面がスマホのカメラ画面風に切り替わる。
- **押している間ピントが合っていく**（ピントリングで可視化）。**指を離した瞬間に撮影**。
- 押している間はこひとの警戒度が上がりやすい。「どこまで粘るか」が駆け引きになる。
- 写真の評価軸:
  1. **写っている範囲**: 一部だけ／半身／全身（ファインダー枠にどれだけ収まっているか）
  2. **ピント**: 押し続けた時間
  3. **距離**: 近いほど評価が高いが、近づくほど逃げられやすい
  4. **決定的瞬間**: あくびをする、しずくを舐めるなど、一定の確率で起きる特別な行動
- 写真の評価に応じて、アルバムのメモが「目撃 → 生態メモ → 鳴き声」と段階的に埋まっていく。
- こひとに気づかれると、そのこひとは逃げる（同じ時間帯にはもう出てこない）。

### クリア条件

- ほかのこひとから5つのヒントを集め、かくれたれじりの**全身写真**を撮る。

## 5. 技術方針（確定）

- HTML5 Canvas（2D）を使うブラウザゲーム。スマホの縦画面を優先する。
- **ゲームライブラリは使わない。** 素の TypeScript + Canvas で書く。
  MVP の規模（タイル描画・数体のNPC・カメラ画面・アルバム）に対して
  フレームワークは過剰で、仮絵（図形・SVG）とも相性がよい。重くなったら後から寄せる。
- ビルドは Vite、型は TypeScript。テストは Vitest（ロジック部分のユニットテスト）。
- マップ: 最初はコード内にタイル配列を直接書く。後で Tiled などへ移すことを検討する。
- セーブ: ブラウザの localStorage（アルバムと進行状況）。
- 実装は Codex CLI が行い、こちら（Claude）で検査とレビューをする。
