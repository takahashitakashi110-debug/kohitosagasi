# P0　ほほもちの朝を撮り、自室に飾る

## 目的

架空の町「あつひ」で暮らすアラフィフの女性が、自室から住宅街の植え込みへ歩き、ほほもちの朝の習慣を観察する。一人称3Dで撮った実写真を自室に飾り、メモを添え、同じ配信元で開き直せる一巡を作る。設計の基準は2026年11月23日のシステムドラフトv0.3、レビュー反映v0.1、制作開始パックv0.1、P0契約v0.1。

## 変更範囲

- 新規の prototype3d.html、src/prototype3d/、tests/prototype3d/、e2e/prototype3d.spec.ts を中心とする。
- src/data/text.ts、package.json、package-lock.json、vite.config.ts、playwright.config.ts は新入口・依存・日本語表示・PC検証の接続に限る。README.md、docs/HANDOVER.md とこの依頼書を更新できる。
- 2Dのゲーム・シーン・資産・保存領域・入口・重要テスト5本を保護する。旧採点式、自動終了、移動時の時間進行を3Dに流用しない。既存の2D制作PRとは独立して作業する。
- 正式な原画とGLBは既存素材チャット経由。本試作は頬・小さな手・木の実の動きを読めるコード造形を使う。

## ゲームと受入条件

1. **AC01–02** 自室から道を歩ける。葉に載った左右が磨かれた実が見え、手元の実とは別に調べられる。音を消しても発見できる。
2. **AC03** 朝にほほもちが木の実を持ち直し、頬に当てる動作を繰り返す。同じ瞬間の構図、見える部位、距離、面積、ピントから姿と生態を判定する。最初の生態写真一枚で両記録を得られる。
3. **AC04–05** 異なる構図を自由に撮り、部屋でどの実写真も展示できる。画像Blob・撮影情報・選択・日本語自由メモ・仮説のしおり・獲得記録を同じ配信元の再読込後に復元する。展示の差し替えで進行を失わない。しおりで再訪時の観察候補を変える。
4. **AC06** 転がった実を拾い、葉に返すと本人が拾って見せる。交流・二枚目の写真・メモ入力は生態や展示の条件にしない。
5. **AC07–08** 着座と休憩を区別し、家またはベンチで確認して休むときだけ朝→昼→夕→夜→翌朝と進む。朝以外にも痕跡があり翌朝に再会できる。物音で隠れた場合は、距離を戻して静かに待つと撮り直せる。
6. **AC09–10** 保存失敗は未保存と表示して遊びを続けられる。欠けた記録や読めない写真で落ちず、定型絵での復元は行わない。手帳・設定・交流中の操作を歩行・撮影から分離する。Escで戻れる。
7. **AC11** 既存2Dと3Dの型チェック・テスト・ビルドを通す。2Dの保存を上書きしない。
8. **後続条件 AC12–15** 夕の折り葉から夜のかさこそりへ。未交流でもハッピー後の共存に進める。主役の撮影後も散策を続け、寄り添いと代償の説明の後に明示的に選択する。P0に終盤への近道は設けない。

## 検証と引き継ぎ

進行・写真の視認性・入力・時刻に単体検査を追加。実ブラウザでは1280×720と1920×1080で歩行、撮影、任意展示、日本語メモ、同一配信元リロードを行い、画像の内容と相違・復元を確かめる。既存2D検査、異常系、スクリーンショット、対象コミットを記録する。10〜15分は調整用の仮目標。所要時間と正式キャラの魅力は人による試遊で評価する。
