# こひとさがし

雨のない夏のまち「あつぎ」を歩いて、6体のこひとを写真に残す Canvas 2D ゲームです。
主人公は夏休みの1週間だけ、おばあちゃんの住む町へ遊びに来た子どもです。

今回の版は遊べる2D試作です。こひとは小さく移動して、ときどき立ち止まります。
町には変わった日課を持つ大人4人もいて、撮ると「町の人でした！」という結果になります。
対象が近くに複数いるときは「被写体をかえる」で選べます。
設計と実装契約は `docs/GAME_DESIGN.md` / `docs/MVP_SPEC.md` を参照してください。

## 起動

Node.js 20.19 以降（または 22.12 以降）が必要です。

```sh
npm install
npm run dev
```

PowerShell で `npm.ps1` が実行制限にかかる場合は、`npm.cmd install` / `npm.cmd run dev` を使えます。

```sh
npm run typecheck
npm test
npm run build
```

`dist/` が静的配信する成果物です。ゲーム中に外部サービスへ通信しません。
Runwayで作成した画像と撮影・ヒント・町の人・エンディングの効果音はローカル同梱です。
保存先はブラウザの localStorage です。保存できない環境では、そのページを開いている間だけ記録を保持します。

夏の町のタイトル画像とこひと14フレームは `src/assets/summer/` に同梱しています。
読み込み中・失敗時は従来の図形描画で遊べます。`npm run dev` 後に
`/tools/summer-preview.html` で通常姿・決定的瞬間・隠れ尻を実寸と3倍で確認できます。
`/tools/motion-preview.html` では10キャラと隠れ尻の連続コマを確認できます。

ビルド後に `python scripts/package-prototype.py /path/to/output` を実行すると、
画像・音を含む単体の `kohitosagasi-prototype.html` と、静的配信用ZIPを作れます。
単体HTMLはChromeやEdge等で開くと、そのままオフラインで遊べます。

## 操作

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 左下のスティック | WASD / 矢印 |
| 忍び足 | スティックを半分以下に倒す | Shift を押しながら移動 |
| 撮影 | カメラを長押しして離す | Space またはカメラボタンを長押しして離す |
| 撮影中の画角 | スティック左右 | A / D または左右矢印 |
| アルバム | 右上のボタン | Tab |
| キャンセル / 戻る | 画面のボタン | Esc |
| 地図の選択・決定 | 行き先をタップ | 矢印 / WASD、Enter / Space |
| アルバムのページ・タブ | 画面のボタン | 左右でページ、上下でタブ、Enter で戻る |

時間は別のスポットへ移動したときだけ進みます。5つの生態メモを集めると、アルバムの「すいり」から最後の居場所がわかります。
