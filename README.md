# こひとさがし

雨のない夏のまち「あつぎ」を歩いて、6体のこひとを写真に残す Canvas 2D ゲームです。
設計と実装契約は `docs/GAME_DESIGN.md` / `docs/MVP_SPEC.md` を参照してください。

## こひとさがし3DのP0試作

架空の町「あつひ」に暮らす主人公の自室から、朝の植え込みまで歩くPC向けの試作です。葉の上の実を調べ、ほほもちが実を頬に当てる様子をカメラで観察できます。

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1 --port 5183 --strictPort
```

WebGL 2に対応したブラウザで [3D試作を開いてください](http://127.0.0.1:5183/prototype3d.html)。WASDで歩き、画面のドラッグまたは矢印キーで視点を動かします。Eで近くを調べ、右クリックでカメラ、左クリックで撮影、ホイールでズームできます。Ctrlでしゃがみ、Shiftで走れます。

帰宅してEから「自室のフレーム」を開くと、撮った写真を選んで飾れます。Tabで開く観察手帳にも、写真ごとの日本語メモと仮説のしおりが残ります。画像と記録はIndexedDBに自動保存します。「保存済み」の表示を確認し、次回も同じブラウザの同じURLで開いてください。家とベンチの休憩は確認後に時間帯を一つ進めます。

`npm.cmd run e2e` で既存2DとPCの3D操作を検査できます。Chromiumの準備と既存ブラウザを指定する方法は [引き継ぎ書](./docs/HANDOVER.md) にあります。P0の受入条件は [ほほもちの依頼書](./docs/REQUEST_P0_HOHOMOCHI.md) に記載しています。

## 起動

Node.js 20.19 以降（または 22.12 以降）が必要です。

```sh
npm install
npm run dev
```

PowerShell で `npm.ps1` が実行制限にかかる場合は、`npm.cmd install` / `npm.cmd run dev` を使えます。

```sh
npm run typecheck
npm test
npm run build
```

`dist/` が静的配信する成果物です。ゲーム内での外部通信、外部画像、音声、Web フォントはありません。
保存先はブラウザの localStorage です。保存できない環境では、そのページを開いている間だけ記録を保持します。

## 操作

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 左下のスティック | WASD / 矢印 |
| 忍び足 | スティックを半分以下に倒す | Shift を押しながら移動 |
| 撮影 | カメラを長押しして離す | Space またはカメラボタンを長押しして離す |
| 撮影中の画角 | スティック左右 | A / D または左右矢印 |
| アルバム | 右上のボタン | Tab |
| キャンセル / 戻る | 画面のボタン | Esc |
| 地図の選択・決定 | 行き先をタップ | 矢印 / WASD、Enter / Space |
| アルバムのページ・タブ | 画面のボタン | 左右でページ、上下でタブ、Enter で戻る |

時間は別のスポットへ移動したときだけ進みます。5つの生態メモを集めると、アルバムの「すいり」から最後の居場所がわかります。
